# Kealing Terminus
---

This is a command line adventure game modeled after [MIT Terminus](https://web.mit.edu/mprat/Public/web/Terminus/Web/main.html). MIT Terminus is how I learned to use the command line, however the story had some loose ends and it didn't work for Linux. 

Improving on those are two of the upgrades I implemented in my version
