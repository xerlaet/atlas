# Tame Problem
---

Opposite of a [Wicked Problem](/notes/wicked-problem)

1. Can be completely specified
2. The specification and solution can be separated
3. There are stopping rules
4. The solution can be evaluated as correct or incorrect
5. Each step has a finite number of possible moves
6. There is a definite chain of cause-effect reasoning
7. The solution can be tested immediately and remains correct forever
8. The solution can be adapted for similar problems
9. The solution process is a scientific process
10. If the problem is not solved, try again

## Examples
Chess playing, math problems, operations research
