# WiFi
---

**802.11** (commonly known as WiFi) is a set of standards and protocols

![[Pasted image 20251104105059.png|500]]

WiFi 6 is the dominant protocol today

[[CSMA(CA)]] is used because it is difficult to detect collisions, so the goal is to avoid collisions entirely

The **Basic Service Set** (BSS) contains wireless hosts, an access point (AP), and ad hoc mode

The spectrum is divided into channels at different frequencies. An arriving host associates with an AP
1. scans channels to listen for beacon frames with the AP's SSID and MAC address
2. select an AP to associate with
3. perform authentication
4. run DHCP in the AP's subnet

Passive scanning vs active scanning (active scanning is preferred because it uses less energy overall)
