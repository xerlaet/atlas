# Software Engineering
---

**Software Engineering** is a systematic process of creating useful software starting from market research and specifications through coding, testing, and maintenance

Well written software should be 
- easily maintainable
- dependable and secure
- efficient
- acceptable for the userbase

There are many different software development processes, the goal being to have a framework for designing software
- specify what the system should do
- design/implement the organization
- validate the system based on the customer criteria
- evolve the system in response to changing needs

## Requirements Engineering
**Requirements Engineering** is the process of defining, documenting, and maintaining requirements

A **software requirement** is a property that must be exhibited by something to solve a problem

A **functional requirement** can be verified as an individual feature, a **nonfunctional requirement** can be verified at the system level
