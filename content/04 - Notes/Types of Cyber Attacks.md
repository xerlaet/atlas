# Types of Cyber Attacks
---

## Password Attacks
- **Online Guessing**: Attempts passwords through an authentication service
- **Offline Guessing**: Tests password guesses against stolen hashes without contacting the service
- **Brute-Force Attack**: Repeatedly tries passwords or cryptographic keys until successful

## Network Attacks
- **Passive Attack**: Eavesdrops on communications without modifying them
- **Active Attack**: Modifies, replays, injects, or deletes messages
- **Man-in-the-Middle (MITM)**: Intercepts and potentially modifies communications between parties
- **Replay Attack**: Retransmits captured messages to repeat an action
- **Reflection Attack**: Reuses protocol responses across sessions to impersonate a participant
- **Spoofing**: Forges an identity or message source
- **Denial-of-Service (DoS)**: Overwhelms resources to prevent legitimate access
- **Distributed Denial-of-Service (DDoS)**: Overwhelms resources using multiple attacking systems

## Malware
- **Trojan Horse**: Malware disguised as legitimate software
- **Virus**: Malware that attaches to files and replicates when executed
- **Worm**: Self-replicating malware that spreads between systems
- **Backdoor**: Hidden method of bypassing normal security controls
- **Bot**: Compromised device remotely controlled by an attacker
- **Logic Bomb**: Malicious code triggered by a specific condition
- **Ransomware**: Malware that encrypts files or locks systems for ransom

## Application Attacks
- **SQL Injection**: Injects malicious SQL to manipulate database queries
- **Privilege Escalation**: Exploits weaknesses to gain higher-level permissions
- **Zero-Day Attack**: Exploits a vulnerability before a fix is available

## Social Engineering
- **Phishing**: Uses deceptive messages to steal information or credentials
- **Social Engineering**: Manipulates people into revealing information or compromising security
