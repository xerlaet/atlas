# Artificial Neural Networks
---

**Artificial Neural Networks** (ANNs) are a subset of machine learning inspired by biological neural networks, forming the foundation of modern deep learning.

## Architectures
- [Feedforward Neural Networks](/notes/feedforward-neural-networks) - Basic unidirectional networks
- [Convolutional Neural Networks](/notes/convolutional-neural-networks) - Grid-like data processing
- [Recurrent Neural Networks](/notes/recurrent-neural-networks) - Sequential data processing
- [Long Short-Term Memory](/notes/long-short-term-memory) - RNNs with long-term memory
- [Gated Recurrent Units](/notes/gated-recurrent-units) - Streamlined LSTM alternative
- [Transformer Models](/notes/transformer-models) - Attention-based sequential processing

## Training Mechanics
- [Backpropagation](/notes/backpropagation) - Error calculation algorithm
- [Gradient Descent](/notes/gradient-descent) - Weight optimization method
- [Activation Functions](/notes/activation-functions) - Introducing non-linearity
