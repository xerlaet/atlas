# ARP
---

**Address Resolution Protocol** (ARP) is a protocol to determine an interface's MAC address

When a device enters a network, they broadcast to everyone

Each host and router on the LAN has an ARP table containing a mapping of IP addresses to MAC addresses with a TTL until they are forgotten

Similar to [DNS Cache Poisoning](/notes/dns-cache-poisoning), ARP can have the same issue yet you have to be on the same subnet so its less common
