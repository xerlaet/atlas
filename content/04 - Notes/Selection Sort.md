# Selection Sort
---

The list is divided into a sorted and unsorted part. Iteratively the smallest element is selected from the unsorted array and swapped with the leftmost unsorted element. Selecting the largest each time works just as well

![Pasted image 20250311092527.png](/attachments/Pasted%20image%2020250311092527.png)

## Complexity
$\Theta(n^{2})$ because each time the maximum needs to be selected taking $n-i$ checks in the worst and best case
