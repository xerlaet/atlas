# MAC Address
---

The **MAC address** is a 48-bit address that is unique for each device

Because it's unique devices can be tracked, although they are only discoverable from within the same subnet

Reasons for MAC addresses
- allow really fast lookup for switches
- can support other network-layer protocols not just IP
- if switches had IP addresses, they would need to be configured whenever they are moved - instead they are designed to easily plug into a network and basically be invisible

broadcast address is FF-FF-FF-FF-FF-FF
