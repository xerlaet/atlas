# Registers
---

**Registers** are used to store and manipulate data between clock cycles

![Pasted image 20250401132633.png](/attachments/Pasted%20image%2020250401132633.png)

A register address entered into A1 or A2 will output the data from that register in RD1 or RD2
If WE3=1, then WD3 will be written into register A3

![Pasted image 20250401133227.png](/attachments/Pasted%20image%2020250401133227.png)

RD is read from address A
If WE=1, WD is written into address A
