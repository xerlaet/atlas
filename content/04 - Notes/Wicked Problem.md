# Wicked Problem
---

Opposite of a [Tame Problem](/notes/tame-problem)

1. Cannot be completely specified
2. The specification and solution cannot be separated
3. There are no stopping rules
4. The solution can only be evaluated subjectively
5. Each step has an infinite number of moves
6. Cause-effect reasoning is premise-based but hard to tell which is best
7. The solution is subject to lifelong testing
8. Each wicked problem is unique
9. The solution process is a political process
10. Incorrect solutions have disastrous consequences

## Examples
urban planning, policy making, economic reforms, software development
