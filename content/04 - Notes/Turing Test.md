# Turing Test
---

Proposed by [Alan Turing](/notes/alan-turing) as a thought experiment that if a computer can pass as a human would it then be considered intelligent?

The consensus is no because the Turing Test has already been passed and computer intelligence is still being debated

It would appear that any computer would need
- natural language processing to communicate successfully
- knowledge representation to store what it knows
- automated reasoning to answer questions and draw conclusions
- machine learning to adapt to new circumstances and detect patterns

A refined **total Turing Test** would require interaction with objects and people in the real world, requiring
- computer vision to perceive the world
- robotics to manipulate objects and move about

Focusing on the Turing test or any one benchmark is probably problematic—artificial flight succeeded when engineers stopped imitating birds and started using wind tunnels and learning about aerodynamics
