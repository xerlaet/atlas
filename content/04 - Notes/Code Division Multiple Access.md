# Code Division Multiple Access
---

**Code Division Multiple Access** (CDMA)

A unique code is assigned to each user to encode data so multiple users can transmit simultaneously

[[Medium Access Protocols]]

Data is both encoded and decoded by multiplying the data by the **chipping sequence**

![[Pasted image 20251104104832.png|500]]

This works because of orthogonality or something (Orthogonal frequency division multiplexing?)

It got phased out because there weren't enough chipping sequences to go around of a short enough length
