# SR Latch
---

A **SR latch** has a set and reset bit
![Pasted image 20250306132253.png](/attachments/Pasted%20image%2020250306132253.png)
![Pasted image 20250306132318.png](/attachments/Pasted%20image%2020250306132318.png)
When S=1,R=0,Q=1 (set)
When S=0,R=1,Q=0 (reset)
When S=R=0, Q=Q (hold)

When S=R=1, $Q=\bar{Q}=0$ (avoid this!)
