# Classification Evaluation Metrics
---


|          |               Positive                |                    Negative                     |                                         |
| :------: | :-----------------------------------: | :---------------------------------------------: | :-------------------------------------: |
| Positive |          True Positive (TP)           |     False Negative (FN)<br>(Type II Error)      |    Sensitivity<br>$\frac{TP}{TP+FN}$    |
| Negative | False Positive (FP)<br>(Type I Error) |               True Negative (TN)                |    Specificity<br>$\frac{TN}{TN+FP}$    |
|          |    Precision<br>$\frac{TP}{TP+FP}$    | Negative Predictive Value<br>$\frac{TN}{TN+FN}$ | Accuracy<br>$\frac{TP+TN}{TP+TN+FP+FN}$ |

Accuracy
Precision
Recall

**Sensitivity** (True Positive Rate): $P(\text{Tests positive}\mid \text{Is Sick})$
**Specificity** (True Negative Rate): $P(\text{Tests Negative}\mid \text{Is Healthy})$
