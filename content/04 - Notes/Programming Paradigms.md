# Programming Paradigms
---

## Imperative Programming
[Procedural Programming](/notes/procedural-programming) groups code into procedures or functions
[Object-Oriented Programming](/notes/object-oriented-programming) groups code into states with objects

## Declarative Programming
[Functional Programming](/notes/functional-programming) treats computation as the evaluation of functions
[Logical Programming](/notes/logical-programming) uses formal logic to prove queries
