# Extended Reality
---

[[Virtual Reality]] (VR) replaces reality
**Augmented Reality** (AR) enhances reality

>[!abstract] Definitions
**Perception**: How we experience reality (five senses)
**Presence**: the perception of existing in the virtual environment

## Foundations
### History
1957 - Sensorama by Morton Heilig
1995 - Nintendo Virtual Boy
2006 - Nintendo Wii
2012 - Oculus Kickstarter, Google Glass revealed
2014 - Google cardboard
2016 - Oculus Rift, HTC Vive, PlayStation VR
2020 - Meta Quest 2
2024 - Apple Vision Pro

## Hardware
### Output Devices
Present information to the user's senses through the perceptual system
- Displays (single-screen, surround-screen, head-worn, arbitrary)
- Sound (headphones, speakers)
- Haptics (ground vs body referenced, kinesthesia vs tactile)

### Input Devices
Devices that convey information from the user into the application
- Keyboard and mouse
- Joysticks
- Stylus, touch devices
- Tracking (inside-out vs outside-in)
- Treadmills
- Brain input (EEG)

## Interaction Layer
### Travel
Walking (full vs partial gait, treadmills)
Steering (gaze vs hand vs torso vs lean directed)
Selection-Based (target vs route based)
Teleportation (point to where you want to go)

### Manipulation
Selection, positioning, rotation, scaling

Grasping (one-to-one virtual hand, go-go)
Pointing
- vector based - ray-casting, fishing reel
- volume-based - flashlight, aperture selection
Indirect (use proxies for interactions also called world-in-miniature)
Hybrid (combine various techniques together)

### System Control
Issuing commands to change the system state (launching apps, menu)

Physical controllers
Graphical menus (floating vs tulip)
Gestures (static configurations vs dynamic movements)
Tools (physical or virtual objects)
Task sequences (ex. object-action-parameter)
