# Programming Languages
---
Programming languages are languages designed to tell computers what to do

## [[Web Programming]]
### [[HTML]]
HTML (HyperText Markup Language) is a markup language used to format the appearance of information on a website
### CSS
CSS (Cascading Style Sheets) is responsible for governing the size, color, and position of page elements. It is called *cascading* because an applied style will cascade from parent elements down to all children elements
### [[JavaScript]]
JavaScript is used to manage the behavior of web pages such as animated graphics, interactive maps, and clickable buttons
### SQL
SQL (Structured Query Language) is used to query and manipulate databases

## General Purpose Programming
### [[Python]]
Python is a high-level programming language that is very simple to learn and one of the most popular languages in the world
### Java
Java is a general use object oriented programming language that has a "write-once, run-anywhere" philosophy due to the Java Virtual Machine (JVM)
### [[C++]]
C++ is an improvement from C which is popular for OS and general application development
