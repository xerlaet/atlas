# Evolution of Programming Languages
---

[Plankalkül](/notes/plankalkl) was the first high-level programming language designed by Konrad Zuse. Due to the war he developed the language in isolation and it was remarkably complete for its time, only published much later in 1972

[Pseudocode](/notes/pseudocode) is a human readable way to describe algorithms before actual implementation. Memory management was a standard problem that was a motivation for assembly languages

The [IBM 704](/notes/ibm-704) included indexing and floating point instructions in hardware, and paired well with [Fortran](/notes/fortran) as the control statements were based on 704 instructions. Fortran claimed that the compiled code would be half as efficient as what could be produced by hand which was crazy for the time, and it was true!

[LISP](/notes/lisp) was one of the first [Functional Programming](/notes/functional-programming) languages built for AI, needing to process symbolic data in linked lists - John McCarthy

[Prolog](/notes/prolog) was a [Logical Programming](/notes/logical-programming) language also for AI and expert systems

[Java](/notes/java) is a high level object oriented language known for its portability

[C](/notes/c) was a foundational programming language but has incomplete type checking

[Perl](/notes/perl) is a powerful scripting language, originally for text processing and then in web development

[Python](/notes/python) is a high level interpreted language known for its readability

[Ruby](/notes/ruby) is a dynamic object oriented language with nice syntax, designed out of dissatisfaction with Perl and Python

[Ada](/notes/ada) was part of a massive effort to design a language for the DoD, with lots of exception handling. It took 4 years for usable compilers to appear after the language was decided - it was very large and complex

[COBOL](/notes/cobol) was designed for businesses, and worked really well. Very little software development has taken place trying to recreate it or something like it that is better. It focused on english for ease of use

[SNOBOL](/notes/snobol) was designed for text processing

[Pascal](/notes/pascal)

[SmallTalk](/notes/smalltalk) was the first to fully support OOP

[Scheme](/notes/scheme) emerged in the 1970s treating functions as first class entities, basically extending lisp

[Racket](/notes/racket)

[Haskell](/notes/haskell)
