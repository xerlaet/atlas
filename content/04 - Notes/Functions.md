# Functions
---
A **function** is a mapping that takes an input and produces an output. The set of inputs is the **domain** and the outputs are the **range**
$$
f:D\to R
$$

As opposed to a **method**, which transfers information from one object to another

A function is **one-to-one** if each input is mapped to a unique output and vise versa, **onto** if the range is fully covered by the mapping, and not a function if an input is mapped to multiple outputs
