# Algorithms
---

An **algorithm** is a finite sequence of instructions to solve a problem or perform a computation

## Analysis
An algorithm is **correct** if it both halts and produces the correct output for all valid inputs
An search algorithm is **complete** if it always finds a solution when it exists
An algorithm is **optimal** if it finds a least-cost solution

[[Time Complexity]] analyzes the number of steps an algorithm takes to run
[[Space Complexity]] analyzes the amount of memory an algorithm consumes

Recursive algorithms can be analyzed using [[Recurrence Relations]]

## Algorithmic Design Paradigms
[[Algorithmic Design Paradigms]] are general strategies for designing algorithms
