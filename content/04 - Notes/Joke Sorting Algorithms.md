# Joke Sorting Algorithms
---

**Descartes Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Question if there is anything to even sort in the first place

**Gaslight Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Tell the user the array is already sorted

**Moving Goalpost Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Redefine numbers in mathematics such that the array is sorted

**User Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Open a GUI and ask the user to sort the array themselves (similar to **Intern Sort**)

**Undefined Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Mark the space taken by the array as free, and check back later to see what took its place and hope for the best

**Jesus Sort** $\text{Time}=O(1),\text{Space}=O(1)$
Select either the first or last element to ascend into a new array. The last shall become first and the first shall become last in the kingdom of one element arrays


**Overwrite Sort** $\text{Time}=O(n),\text{Space}=O(1)$
Iterate through the array setting each element to its index

**Stalin Sort** $\text{Time}=O(n),\text{Space}=O(n)$
Iterate through the array, and send any element that is out of order to the Gulag

**Lookup Sort** $\text{Time}=O(n),\text{Space}=O(n)$ \*doesn't include preprocessing
Precompute sorted versions of all possible lists and store them in a hash table

**Sleep Sort** $\text{Time}=O(n+k),\text{Space}=O(n)$
Assign each element its own thread with a sleep time of its value to add itself to a new array


**Cosmic Ray Sort** $\text{Time}=O(\infty),\text{Space}=O(1)$
Wait for cosmic rays to sort the array (similar to **Miracle Sort**)

**Random Sort** $\text{Time}=O(\infty),\text{Space}=O(1)$
Randomize the order of elements in the array, if still unsorted then repeat

**Wikipedia Sort** $\text{Time}=O(\infty),\text{Space}=O(n)$
Publish the array to Wikipedia and wait for a user to edit it along with an admin to accept it
