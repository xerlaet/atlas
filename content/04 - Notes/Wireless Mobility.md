# Wireless Mobility
---

There is a spectrum of mobility. Can the device move among access points in a single or multiple provider network, and can the device maintain ongoing connections while doing so?

Each device has a **home network**, and is considered **roaming** when connected to a **visited network**. The home network serves as a coordination place where information about a device can be found
