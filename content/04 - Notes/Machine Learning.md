# Machine Learning
---

## Problem Tasks
- [Classification](/notes/classification) - Predicting discrete class labels
- [Regression](/notes/regression) - Predicting continuous numerical outputs
- [Clustering](/notes/clustering) - Grouping similar unlabeled data points
- [Dimensionality Reduction](/notes/dimensionality-reduction) - Compressing data while retaining key information
- [Sequence Learning](/notes/sequence-learning) - Processing time-series or text data
- [Object Detection](/notes/object-detection) - Locating and classifying image elements
- [Image Segmentation](/notes/image-segmentation) - Classifying images at pixel level
- [Generative Modeling](/notes/generative-modeling) - Create new media

## Learning Paradigms
- [Supervised Learning](/notes/supervised-learning) - Learning from labeled example data
- [Unsupervised Learning](/notes/unsupervised-learning) - Finding patterns in unlabeled data
- [Reinforcement Learning](/notes/reinforcement-learning) - Learning via state, action, reward

## Model Families
- [Neural Networks](/notes/neural-networks) - Learn features through gradient descent
- [Decision Trees](/notes/decision-trees) - Recursive spatial partitioning
- [k-Nearest Neighbors](/notes/k-nearest-neighbors) - Instance-based local distance matching

## Core Concepts
- [Manifold Hypothesis](/notes/manifold-hypothesis) - Data often lies in a lower-dimensional structure
- [Data Preprocessing](/notes/data-preprocessing) - Cleaning and formatting raw inputs
- [Regularization](/notes/regularization) - Penalizing complexity to prevent overfitting
- [Bias, Variance, and Noise](/notes/bias-variance-and-noise) - Balancing underfitting and overfitting

## Evaluation
- [Classification Evaluation Metrics](/notes/classification-evaluation-metrics) - Quantifying model accuracy and errors
- [ROC Curves](/notes/roc-curves) - True Positive vs False Positive
- [Cross-Validation](/notes/cross-validation) - Estimating model performance on subsets
