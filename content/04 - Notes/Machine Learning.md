## Problem Tasks
- [Classification](/notes/classification) - Predicting discrete class labels
- [Regression](/notes/regression) - Predicting continuous numerical outputs
- [Clustering](/notes/clustering) - Grouping similar unlabeled data points
- [Dimensionality Reduction](/notes/dimensionality-reduction) - Compressing data while retaining key information
- [Sequence Learning](/notes/sequence-learning) - Processing time-series or text data
- [Object Detection](/notes/object-detection) - Locating and classifying image elements
- [Image Segmentation](/notes/image-segmentation) - Classifying images at pixel level

## Learning Paradigms
- [Supervised Learning](/notes/supervised-learning) - Learning from labeled example data
- [Unsupervised Learning](/notes/unsupervised-learning) - Finding patterns in unlabeled data
- [Self-Supervised Learning](/notes/self-supervised-learning) - Generating labels from data
- [Semi-supervised Learning](/notes/semi-supervised-learning) - Combining labeled and unlabeled data
- [Reinforcement Learning](/notes/reinforcement-learning) - Learning via state, action, reward
- [Online vs Offline Learning](/notes/online-vs-offline-learning) - Continuous update versus batch training

- [Neural Networks](/notes/neural-networks) - Learn features through gradient descent
