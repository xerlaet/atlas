# Compilation
---
**Compilation** is when programs are translated into machine language to be executed directly on the computer with fast execution times (C, COBOL, C++)

The compiler reads the **source language** and creates the compiled result

![Pasted image 20250305021332.png](/attachments/Pasted%20image%2020250305021332.png)

Compilers might use **optimization** which improves programs by making them smaller or faster

Other programs are linked together with it.

A **preprocessor** is a program that processes a program just before it is compiled, to do things like include library files
