# Ontological Argument
---

1. It is logically possible that a "maximally great being" exists (a being with maximal excellence such as omniscience, omnipotence, moral perfection)
2. Because it is a maximally great being, if it exists in one possible world, it must exist necessarily in all possible worlds
3. Therefore, it exists in the actual world

## Analysis
With this argument, saying that a maximally great being could exist guarantees that it will exist. But what about saying that it's logically possible a maximally great being does not exist? That would imply that it doesn't exist in any world

The first premise is really saying: There is at least one possible world where a maximally great being who has to exist in every possible world exists. That is assuming the conclusion - it seems to be a minor reasonable conclusion at first but is actually circular. I think many people (myself included) have a different understanding of possible worlds.

Gödel made a formulation based on "positive properties", however if those positive properties were made into a set there's no reason to believe that it will be theologically interesting, or that there is only one set of such properties.

## Stance
I think it's possible that God exists, but also that it's possible God doesn't exist. Under modal logic this is apparently an invalid statement because God has to exist in either every possible world or none of them.

So I believe the correct statement instead of saying it's possible and not possible is to be agnostic and not know if it's possible that God exists.
