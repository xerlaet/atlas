# Software Testing
---

**Software testing** aims to detect defects and undesirable behavior in software. A test is successful if it finds a mistake

[White Box Testing](/notes/white-box-testing) takes into account the internal mechanism of the system
[Black Box Testing](/notes/black-box-testing) ignores the internal mechanisms of the system and solely focuses on the inputs and outputs

**Unit Testing** involves testing the individual modules and classes

**Integration Testing** involves testing the interfaces among the modules or components

**System Testing** involves recovery, security, stress, and performance testing

**Acceptance Testing** involves a user or customer testing the product themselves

**Regression Testing** involves retesting select components that have been modified
