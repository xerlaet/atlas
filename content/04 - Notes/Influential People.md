## Computer Science
[Charles Babbage](/notes/charles-babbage) designed the analytical engine which was an early mechanical computer, laying the foundation for modern computing

[Ada Lovelace](/notes/ada-lovelace) wrote the first algorithm for Babbage's machine, becoming the first computer programmer

[Alan Turing](/notes/alan-turing) developed the Turing Machine model, laying a foundation for theoretical computation

[Grace Hopper](/notes/grace-hopper) at UNIVAC developed the first compilers

[John von Neumann](/notes/john-von-neumann) introduced the [von Neumann Architecture](/notes/von-neumann-architecture) influencing [Imperative Programming](/notes/imperative-programming)

[John Backus](/notes/john-backus) led the development of [Fortran](/notes/fortran) which was the first high-level programming language, and created the Backus-Naur Form for syntax definition

[Donald Knuth](/notes/donald-knuth) developed the Art of Computer Programming and many computer algorithms

[Brian Kernighan](/notes/brian-kernighan) and [Dennis Ritchie](/notes/dennis-ritchie) created the C programming language which has influenced many languages since
