## Computer Science
[[Charles Babbage]] designed the analytical engine which was an early mechanical computer, laying the foundation for modern computing

[[Ada Lovelace]] wrote the first algorithm for Babbage's machine, becoming the first computer programmer

[[Alan Turing]] developed the Turing Machine model, laying a foundation for theoretical computation

[[Grace Hopper]] at UNIVAC developed the first compilers

[[John von Neumann]] introduced the [[von Neumann Architecture]] influencing [[Imperative Programming]]

[[John Backus]] led the development of [[Fortran]] which was the first high-level programming language, and created the Backus-Naur Form for syntax definition

[[Donald Knuth]] developed the Art of Computer Programming and many computer algorithms

[[Brian Kernighan]] and [[Dennis Ritchie]] created the C programming language which has influenced many languages since
