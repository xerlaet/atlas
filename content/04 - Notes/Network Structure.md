# Network Structure
---

Hosts -> Routers & switches -> Links (fiber, copper) -> Protocols (tcp/ip, https)

Each device has a host address, IP address, and MAC address

Network edge (hosts/applications)
Access network (residential, mobile, enterprise)
Network core (interconnected routers)
Physical media (communication links)
