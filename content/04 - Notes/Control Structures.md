# Control Structures
---

Assignment and Comparison > Expression
Control structures and blocks > program statements
subprograms (functions, methods, subroutines, predicates) > program units

> [!tip] 
All algorithms capable of being represented by flowcharts can be coded with simply two-way selection and pretest logical loops

A **control structure** consists of a control statement (the gatekeeper) and the statements whose execution it controls

A **selection statement** provides a mechanism for choosing between multiple paths of execution

```
if control_expression
then clause_1
else clause_2
```

Imperative languages use blocks whereas functional languages use nested expressions

A **loop statement** controls repeated execution, either by iteration or recursion. Counter controlled loops (for statements) are a version of this

A **goto** statement is an unconditional branch, which can often obfuscate
