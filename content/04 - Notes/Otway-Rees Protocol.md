# Otway-Rees Protocol
---

A **trusted intermediary protocol** that uses a KDC to establish a fresh session key between two parties using nonces and symmetric encryption

![TikZ Diagram](/attachments/tikz-79c8a5ca262bb0b0e318c006151a1c15.svg)

$N_{A}$ and $N_{B}$ provide freshness guarantees for Alice and Bob
$M$ binds Alice, Bob, and the session along with authenticating Bob

## Security
- **Nonces**: Link messages to a protocol run and help detect replayed messages
- **Session key**: $K_{AB}$ is generated by the KDC and shared with Alice and Bob
- **Mutual key confirmation**: The 5-message extension lets both parties verify that the other possesses $K_{AB}$
- **Limitation**: Security depends on protecting the long-term keys shared with the KDC
