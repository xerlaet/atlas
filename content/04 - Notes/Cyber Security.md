# Cyber Security
---

The internet wasn't originally designed with security in mind, protocol designers play catch-up

[CIA Triangle](/notes/cia-triangle)
Confidentiality <-> Availability <-> Integrity

**Packet sniffing** is reading the packets sent across a network. This is somewhat solved with encryption
**IP spoofing** is injecting packets with false source addresses
**Denial of service** (DoS) is filling up the bandwidth of a network

Symmetric key - used to decrypt and encrypt
Public key - public to encrypt, private to decrypt

used for digital signatures

hashes

### TLS
confidentiality via symmetric encryption
integrity via cryptographic hashing
authentication via public key cryptography
