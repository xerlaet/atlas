# BitTorrent
---

**BitTorrent** is a peer-to-peer protocol

Computers join by loading a `.torrent` file into a BitTorrent client. The .torrent file will specify a tracker which is a special server keeping track of connected computers, sharing IP addresses of all of them

Once connected, the client can download bits of files in small pieces, as well as upload that data to other clients

**tit-for-tat** is used

requesting chunks
how to keep the network fair
